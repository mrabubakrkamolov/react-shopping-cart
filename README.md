# React State: Shopping Cart (Week 12 homework)

Web Programming K0126_002. Built with React + Vite, using only `useState`.

## Run
```bash
npm install
npm run dev
```

## What is inside
- `ShoppingCart.jsx`: owns the cart state (lifted state), renders the product list and the cart panel
- `ProductList.jsx`: 6 products, Add / Remove buttons
- `CartSidebar.jsx`: items, quantity + / - controls, total computed from state
- `CounterWithHistory.jsx`: the in-class code challenge (count + history + undo)
